How CipherVeil Works

Six precisely engineered steps — from raw plaintext to a visually identical stego image, and back.

📝1
Upload Cover Image & Enter Message
The sender selects any PNG or JPG image as the carrier and types a confidential plaintext message. The image's pixel data will serve as the steganographic container — invisible to anyone without the key.
Carrier Selection
🔐2
AES-256-GCM Authenticated Encryption
The plaintext is encrypted using AES-256 in Galois/Counter Mode. A 128-bit random nonce is generated per session, and the algorithm produces both ciphertext and a 128-bit authentication tag that detects any tampering.
AES-256-GCM
🛡️3
HMAC-SHA3-512 Integrity Authentication
A 512-bit HMAC is computed over the combined payload (ciphertext + nonce + tag) using a secret key. This provides an additional, independent layer of integrity verification separate from AES-GCM's built-in authentication.
HMAC-SHA3-512
🖼️4
DWT SVD Embedding
The full payload (length header + ciphertext + nonce + tag + HMAC) is serialized and embedded using Discrete Wavelet Transform and Singular Value Decomposition techniques. This method provides enhanced security and robustness against various attacks.
DWT SVD Embedding
📤5
Stego Image Output
The resulting image is visually indistinguishable from the original. It can be shared publicly — via email, messaging apps, social media — without raising suspicion. The hidden payload is invisible without the secret key.
Stego Output
🔓6
Extraction, Verification & Decryption
The receiver uploads the stego image and provides the HMAC key. The system extracts the payload via LSB extraction, verifies HMAC-SHA3-512 integrity (any tampering fails here), then decrypts with AES-256-GCM to reveal the original plaintext.
Secure Decryption
